# CSR Generator · Hồ sơ nguồn ban đầu

Đối chiếu ngày 23/11/2026.

| Nguồn | Phạm vi |
| --- | --- |
| IETF, [RFC 2986 §4](https://www.rfc-editor.org/rfc/rfc2986.html#section-4), 11/2000 | Cấu trúc yêu cầu PKCS #10, subject, public key và chữ ký |
| IETF, [RFC 5280 §4.2.1.6](https://www.rfc-editor.org/rfc/rfc5280.html#section-4.2.1.6), 05/2008 | Tên thay thế kiểu DNS |
| IETF, [RFC 7468 §7 và §10](https://www.rfc-editor.org/rfc/rfc7468.html#section-7), 04/2015 | Định dạng PEM cho CSR và khóa riêng PKCS #8 |
| [Peculiar Ventures X.509](https://github.com/PeculiarVentures/x509), thư viện 3.1.0 | Mã hóa yêu cầu PKCS #10 và SAN. Web Crypto đảm nhận tạo khóa và ký |
| [CSRGenerator.com](https://csrgenerator.com/) | Tham chiếu luồng nhập subject, SAN và chọn kích thước khóa |

Build web và 25 bài kiểm tra logic đã đạt. Chrome offline tạo được **RSA 2048 và 4096 bit** từ dữ liệu giả lập và từ chối SAN dạng URL. `openssl req -verify -text -noout` xác nhận chữ ký, kích thước khóa và DNS SAN. Khóa công khai từ CSR khớp đầu ra `openssl pkey -pubout` của khóa riêng tải xuống. Rà soát mã giao diện xác nhận **2048 bit là mặc định**, kể cả sau khi bấm Clear. Bản Windows chưa được chạy thử.
