# JSON formatter · JSONC tùy chọn

Ghi nhận ngày 23/11/2026. Thêm chế độ tương thích Torin: comment và trailing comma; đầu ra vẫn JSON chuẩn.

| Tài liệu | Tổ chức | Phiên bản / ngày | Mục áp dụng | URL | Truy cập |
| --- | --- | --- | --- | --- | --- |
| ECMAScript Language Specification | Ecma / TC39 | Living standard | `JSON.parse` / `JSON.stringify` sau bước strip | https://tc39.es/ecma262/multipage/structured-data.html#sec-json.parse | 23/11/2026 |
| Torin JSONC strip | Torin | 2026-11-23 | `//`, `/* */` ngoài chuỗi; trailing `,` trước `}` / `]` | (đặc tả Torin) | 23/11/2026 |

| Hành vi | Nguồn | Bằng chứng |
| --- | --- | --- |
| JSON nghiêm từ chối comment | ECMA-262 | `{"a":1}//x` ném lỗi khi `jsonc` tắt |
| JSONC bỏ comment + trailing comma | Torin strip → parse | Input có `//`, `/* */`, `,` trước `}` → `{"a":1,"u":"http://x"}` |
| Giữ `//` trong chuỗi | Torin strip | `"http://x"` không bị cắt |
| Block comment chưa đóng | Torin | Báo `Unterminated block comment` |

node --import tsx --test --test-name-pattern="JSON formatter" tests/local.test.ts
