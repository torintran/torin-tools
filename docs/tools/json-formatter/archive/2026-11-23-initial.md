# JSON formatter · Hồ sơ nguồn ban đầu

Ghi nhận ngày 23/11/2026 cho mã đang phát triển.

| Tài liệu | Tổ chức | Phiên bản / ngày | Mục áp dụng | URL | Truy cập |
| --- | --- | --- | --- | --- | --- |
| ECMAScript Language Specification | Ecma / TC39 | Living standard | `JSON.parse` | https://tc39.es/ecma262/multipage/structured-data.html#sec-json.parse | 23/11/2026 |
| ECMAScript Language Specification | Ecma / TC39 | Living standard | `JSON.stringify` (space) | https://tc39.es/ecma262/multipage/structured-data.html#sec-json.stringify | 23/11/2026 |

| Hành vi | Nguồn | Bằng chứng |
| --- | --- | --- |
| Format thụt lề 2 | `JSON.stringify(..., null, 2)` | `{"a":1}` → object đa dòng, khóa `"a"` |
| Minify | `JSON.stringify` không space | `{\n "a": 1\n}` → `{"a":1}` |
| Tab indent | space `'\t'` | đầu dòng con bắt đầu bằng tab |
| JSON lỗi | `SyntaxError` từ parse | `{` / chuỗi rỗng ném lỗi |
