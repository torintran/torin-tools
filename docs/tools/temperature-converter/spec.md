# Temperature converter

ID `temperature-converter`. Chuyển đổi nhiệt độ tuyệt đối giữa °C, °F và K. Mặc định 0 °C. Nhận số thập phân hữu hạn với dấu chấm và hỗ trợ ký pháp khoa học.

Từ chối giá trị dưới 0 K theo đơn vị đầu vào hoặc kết quả tràn số. Kết quả hiển thị tối đa 12 chữ số có nghĩa. Ví dụ 0 °C tương ứng 32 °F và 273,15 K. Tính toán tại thiết bị.
