# Text diff · Bố cục kết quả

Cập nhật ngày 23/11/2026. Kết quả có chế độ hai cột và gộp dòng, cùng số dòng, số dòng thêm/xóa và nhãn thiếu xuống dòng cuối. [jsdiff](https://github.com/kpdecker/jsdiff) 9.0.0 tiếp tục tính thay đổi theo dòng. Torin căn các cụm thay đổi để hiển thị; việc ghép hàng không thay đổi kết quả của thuật toán.

Build web và 27 bài kiểm tra logic đạt. Chromium desktop và kích thước mobile đã xác minh cả hai bố cục, số dòng thêm/xóa và dấu hiệu thiếu xuống dòng cuối khi chạy offline.
