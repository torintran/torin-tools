# Postman Backup · Đối chiếu mã hiện có

Ghi nhận ngày 23/11/2026 cho triển khai đã có. Tài liệu API trực tuyến do Postman duy trì, được đối chiếu theo phiên bản hiển thị ngày 23/11/2026. Định dạng archive đầu ra của Torin có phiên bản riêng là `formatVersion: 1`.

| Nguồn | Hợp đồng đã đối chiếu và kiểm tra |
| --- | --- |
| [Postman API Reference](https://learning.postman.com/api-docs/api-reference/#authentication) · [Rate and usage limits](https://learning.postman.com/api-docs/api-reference/#rate-and-usage-limits) | GET qua HTTPS, header `X-API-Key`, mã lỗi 401/429. Kiểm tra retry 429 có giới hạn, hủy trong lúc chờ và giới hạn song song |
| [Get all collections](https://learning.postman.com/api-docs/api-reference/collections/get-collections) · [Get all environments](https://learning.postman.com/api-docs/api-reference/environments/get-environments) | Collection dùng `workspace/limit/offset` làm tham số query, environment lọc theo workspace. Kiểm tra phân trang và trích xuất đối tượng |
| [Get a workspace](https://learning.postman.com/api-docs/api-reference/workspaces/get-workspace) · [Get a collection](https://learning.postman.com/api-docs/api-reference/collections/get-collection) · [Get an environment](https://learning.postman.com/api-docs/api-reference/environments/get-environment) | Các GET chi tiết cung cấp metadata workspace và đối tượng collection/environment dùng để xuất JSON. Kiểm thử giả lập kiểm tra nội dung các mục tương ứng |
| [Get global variables](https://learning.postman.com/api-docs/api-reference/workspaces/get-workspace-global-variables) | GET theo workspace, đọc mảng `values`. Kiểm tra bộ ZIP và cách xử lý lỗi một phần dùng API giả lập |
| [Đặc tả và mã Torin](../spec.md) | Tuyến gateway cho phép, chính sách chuyển tiếp header, tạo manifest và hủy kết quả dở dang. Kiểm tra quyền riêng tư kiểm tra tuyến và header bằng bản giả lập upstream |
