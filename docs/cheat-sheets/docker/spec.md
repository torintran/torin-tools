# Docker

ID `docker`, URL trong app `#cheat-sheets/docker`. Dành cho Docker CLI, Engine và Docker Compose v2.

- Image và registry gồm build, tag, push, pull và liệt kê image.
- Vận hành gồm chạy container trên cổng loopback, xem trạng thái và logs, kiểm tra cấu hình, mở shell và chạy Compose.
- Ví dụ giả định Dockerfile hoặc tệp Compose ở thư mục hiện tại khi lệnh cần chúng. Push cần quyền đối với registry đích.
