# Kubernetes và K3s

ID `kubernetes`, URL trong app `#cheat-sheets/kubernetes`. Dành cho kubectl và lệnh kubectl tích hợp trên máy chủ K3s.

- Chọn context, xem namespace, xem pod, kiểm tra sự kiện và logs.
- Kiểm tra manifest bằng server-side dry run, áp dụng manifest, đổi image GHCR theo tag và theo dõi rollout.
- Ví dụ dùng namespace `apps` và Deployment `my-app`. Dùng context đúng và quyền tương ứng trước khi áp dụng. Với image riêng tư, cluster cần quyền tải từ registry.
