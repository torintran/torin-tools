# Git & GitHub CLI

ID `git-github`, URL trong app `#cheat-sheets/git-github`.

- Git gồm kiểm tra trạng thái, tạo nhánh, stage, xem diff, commit, push và tag.
- GitHub CLI gồm kiểm tra đăng nhập, mở PR, xem CI, tạo release nháp và xem release.
- Các thao tác từ xa dùng quyền của tài khoản đã đăng nhập. Ví dụ phát hành giả định tag đã được đẩy. `git switch` cần Git 2.23 trở lên.
