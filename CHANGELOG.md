# Changelog

## 0.3.0

- Added URL encoding, date-time conversion, JSON and JSONC formatting, whitespace removal, and UUID generation.
- Includes Base64 text and file conversion, local JWT inspection, signing and signature verification, and Postman workspace backup.
- Added English and Vietnamese, keyboard tool search, responsive navigation, and a shared interface using Mantine, Lucide, and the Torin Brand Kit.
- Provides an installable web app, a Docker Compose setup, and Windows x64 installer and portable packages.
- Added contribution and security guidance, plus source and verification records for each tool.
